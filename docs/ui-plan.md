# UI plan

Web UI for pcm, served by `pcm-server`. Design: Claude Design canvas "pcm UI design" (4 screens: Browse, Edit, Current contexts, Sync).

## Decisions

| Topic | Choice |
|---|---|
| Build | Vite + React + TypeScript in `web/`, npm |
| Components | Raystack Apsara (`@raystack/apsara`, Base UI): `Theme` (system light/dark, indigo accent), Search, Badge, Callout, Headline, Text, Flex, Select, Table. Own sidebar tree (`SidebarNav`, CSS modules; heading 15px semibold, items 14px, fixed row height, 12px indent per level). Icons: lucide-react. Design canvas updated to Apsara tokens |
| Routing / data | react-router, TanStack Query (`useQueries` for more than one query) |
| API client | Generated by `@hey-api/openapi-ts` from `docs/swagger/swagger.json` into `web/src/client` (types, SDK, TanStack `queryOptions`). In git; `make client` regenerates; CI checks it is up to date |
| TypeScript | 5.9: hey-api needs the TS compiler JS API, which TypeScript 7 (native) does not have |
| Editor | CodeMirror 6 (`@uiw/react-codemirror`) + preview (react-markdown, remark-gfm) |
| Layout | Sidebar tree (Global / Projects > sections > contexts) + main panel. Table "Current contexts" view per project |
| Saving | Save button + Discard, unsaved warning. No autosave. Data router (`createBrowserRouter`): `useBlocker` dialog (Stay / Leave) for in-app links, `beforeunload` for tab close and reload. Navigation after a save skips the guard |
| Edit routes | `/edit/<id>` (Edit button on the context view), `/new?scope=&project=&section=` ("+" on a sidebar section fills the values). New: pick scope and an existing section, then a name |
| Edit form | Title, Description, Tags (Apsara `Input` chips: Enter adds, × removes). CodeMirror (lazy loaded, `--rs-*` theme) and live preview side by side, stacked on narrow screens |
| Feedback | Toasts: "Saved" (go to the view), "Deleted" (go to `/`, after an AlertDialog confirm), server errors (form keeps the values). Mutations invalidate list, get, search and resolve queries |
| Sections / projects | Sidebar "+" on Global (new section), Projects (new project), each project row (new section in it): Name dialog, stays open on error. "⋯" menu on section and project rows: Delete with confirm; on 409 (not empty) the dialog asks again, "Delete all" sends `force=true`. Go to `/` when the open context is in the deleted section or project. Toasts; tree refreshes |
| Sync | Header "Sync" link with a badge (changes + commits ahead, hidden at 0). `/sync` page: remote · branch, "Sync now" (disabled without remote, info callout with `pcm config set remote <git-url>`), cards Changes / Ahead / Behind (no "Last sync": API has no time), changed files, last 10 commits. 409: conflict callout with files until the next successful sync; other errors in a toast. No polling: refetch on focus and after every change |
| Embed | `web/dist` embedded with `go:embed`. Not in git. No build: placeholder page "UI not built: run make web" |
| Serving | One port: UI at `/` (SPA fallback to `index.html`), API at `/api/v1`, `/health`. Unknown `/api/*`: JSON 404 |
| Bind | `127.0.0.1` only |
| `pcm ui` | Opens browser at `http://127.0.0.1:<config port>`. Server down: error + hint `pcm server start`. `PCM_NO_BROWSER=1`: print URL only |
| Tests | Vitest + Testing Library (components). Browser specs: `@ui` features in `e2e/features/ui/`, run by Node Playwright + playwright-bdd (`web/e2e/`), own CI job. godog skips `@ui`. (playwright-go dropped: its driver CDN is gone) |
| Code style | pcm project contexts `ui/component-props` (props as named `interface`) and `ui/css-modules` (Apsara props + CSS modules with `--rs-*` tokens) |

## Phases (one PR each, specs first)

1. **Skeleton**: `web/` scaffold, embed + placeholder, SPA route, bind 127.0.0.1, `pcm ui`, Makefile, CI. Header (server status) + sidebar (projects, global sections), read-only.
2. **Browse**: full tree (sections > contexts; project loads on expand), full-text search (`/api/v1/search`) in a Cmd+K / Ctrl+K palette (Apsara `Command.Dialog`; header "Search" button too; rows show name, section/scope and snippet; select opens the context), context view at `/contexts/<id>` (rendered md + raw file, "Context not found"), Current contexts table at `/current?project=&section=` (header link). No retry on 4xx.
3. **Edit**
   - 3a: create/edit/delete contexts (fields, CodeMirror, preview, save/discard, unsaved warning).
   - 3b: create/delete sections and projects (sidebar "+" and "⋯" menu, confirm, force on 409).
4. **Sync**: header Sync link + badge, Sync page (status, changed files, log, conflict).
